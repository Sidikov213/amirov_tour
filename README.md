# Амиров-Тур — сайт туроператора

Next.js 16 (App Router) · React 19 · TypeScript. Концепт редизайна amirov-tour.ru.

## Что внутри

- **Главная** (`app/page.tsx`): каталог из 15 экскурсий с фильтром, многодневные туры, форматы, направления, Новый год, вопросы, форма заявки.
- **Страница каждой экскурсии** (`app/tours/[slug]/page.tsx`): собирается статически, со своим заголовком и описанием для поиска, разметкой schema.org и формой брони.
- **Заявки в Telegram** (`app/api/lead/route.ts`): сервер проверяет данные и отправляет заявку менеджеру в чат с кнопкой «Написать в WhatsApp». Если бот не настроен или Telegram недоступен, форма открывает WhatsApp с готовым текстом — заявка не теряется.
- **SEO**: `sitemap.xml`, `robots.txt`, Open Graph, JSON-LD (TravelAgency, TouristTrip, FAQPage), редиректы 308 со старых адресов Tilda (`/derbent` → `/tours/derbent`).
- **Картинки**: `next/image` — сервер сам отдаёт нужный размер и формат под экран.
- **Шрифты** лежат в проекте (`@fontsource`), без запросов к Google.

## Запуск

```bash
npm install
cp .env.example .env.local   # вписать токен бота и id чата
npm run dev                  # http://localhost:3000
```

Продакшен: `npm run build && npm start`, либо импорт репозитория в Vercel.

## Настройка заявок

1. Создать бота у @BotFather, токен — в `TELEGRAM_BOT_TOKEN`.
2. Добавить бота в чат менеджеров (или написать ему лично) и вписать id чата в `TELEGRAM_CHAT_ID`.

## Где менять содержимое

Цены, программы, дни выезда и контакты — в `lib/tours.ts`. Фото — в `public/img/`.
